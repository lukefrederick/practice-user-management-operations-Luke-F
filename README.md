# practice-user-management-operations-Luke-F

In this practice, we tried different options of filtering the different users using the database that we made in practice 1 of the SQL module. 
We tried different methods including SELECT to display different lists of users meeting different criteria, adding users, adding columns and populating those columns, using ALTER to change values for different users, creating concatenated strings using CONCAT, and filtering those, strings, and removed users using DELETE.
